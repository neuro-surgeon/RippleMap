# RippleMap

**RippleMap** — расширение для Visual Studio Code, предназначенное для анализа зависимостей между файлами программного проекта и определения возможного влияния изменений в одном файле на другие части проекта.

## Описание

В процессе разработки программного обеспечения исходные файлы часто связаны между собой с помощью импортов и подключений. Изменение одного файла может повлиять на работу других компонентов программы.

RippleMap позволяет исследовать структуру таких связей, находить зависимости между файлами и определять, какие части проекта могут быть затронуты изменениями.

## Основные возможности

- **Анализ проекта** — поиск исходных файлов и построение графа зависимостей между ними.
- **Анализ отдельного файла** — исследование связей выбранного файла с другими файлами проекта.
- **Анализ влияния изменений** — поиск файлов, которые прямо или косвенно зависят от выбранного файла.
- **Обнаружение зависимостей** — анализ импортов и подключений, используемых в исходном коде.
- **Поддержка нескольких языков программирования** — работа с проектами на C++, Python, JavaScript и TypeScript.
- **Обновление результатов анализа** — повторное сканирование проекта после внесения изменений.

## Установка

Для установки расширения из готового пакета:

1. Откройте Visual Studio Code.
2. Перейдите в раздел **Extensions**.
3. Откройте меню дополнительных действий (`...`).
4. Выберите **Install from VSIX...**.
5. Укажите файл `RippleMap-1.1.0.vsix`.
6. После завершения установки перезагрузите окно редактора.

## Использование

Команды расширения доступны через Command Palette (`Cmd + Shift + P` на macOS или `Ctrl + Shift + P` на Windows/Linux).

| Команда | Описание |
|---|---|
| `RippleMap: Analyze Workspace Dependencies` | Анализ зависимостей во всём рабочем пространстве |
| `RippleMap: Analyze Current File Impact` | Анализ влияния изменений текущего файла |
| `RippleMap: Analyze File Impact` | Анализ влияния изменений выбранного файла |
| `RippleMap: Refresh Dependency Map` | Повторное построение карты зависимостей |

Дополнительно команда анализа выбранного файла доступна через контекстное меню файлов в Explorer.

## Настройки

Расширение предоставляет следующие параметры конфигурации:

| Параметр | Описание | Значение по умолчанию |
|---|---|---|
| `ripplemap.maxFiles` | Максимальное количество файлов, обрабатываемых при анализе рабочего пространства | `10000` |
| `ripplemap.cppIncludeDirectories` | Дополнительные директории для поиска подключаемых C++-заголовков | `["include", "src"]` |

## Разработка

Для установки зависимостей проекта выполните:

```bash
npm install
```

Для проверки типов и сборки расширения выполните:

```bash
npm run compile
```

Для запуска расширения в режиме разработки откройте проект в Visual Studio Code и нажмите `F5`. Будет запущено отдельное окно Extension Development Host.
